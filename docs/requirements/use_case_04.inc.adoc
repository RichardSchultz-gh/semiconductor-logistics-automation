== Use-Case: UC04 Stammdaten anzeigen

=== Kurzbeschreibung
//<Kurze Beschreibung des Use Case>
Der Use Case beschreibt das Anzeigen von Stammdaten, die Grundinformationen über betrieblich relevante Objekte (wie Produkte, Kunden, Personal, Maschine) enthalten.

=== Kurzbeschreibung der Akteure

==== Mitarbeiter

Möchte sich manuell ausgewählte Stammdaten anzeigen lassen.

==== Fertigungsleiter

Möchte sich manuell ausgewählte Stammdaten anzeigen lassen.


=== Vorbedingungen
//Vorbedingungen müssen erfüllt, damit der Use Case beginnen kann, z.B. Benutzer ist angemeldet, Warenkorb ist nicht leer...

*Vorbedingung 1:* Mitarbeiter/Fertigungsleiter ist angemeldet


=== Standardablauf (Basic Flow)
//Der Standardablauf definiert die Schritte für den Erfolgsfall ("Happy Path")

1. Der Use Case beginnt, wenn auf der grafischen Oberfläche der Button "Stammdaten" ausgewählt wird.
3. Nutzer gelangt in Fenster, wo er unter diversen Angaben (Produktes, Kunden, Personal und Maschine...) nach Stammdaten filtern kann.
2. Die gewünschten Stammdaten werden dem Nutzer im selben Fenster tabellarisch angezeigt.
3. Der Use Case ist abgeschlossen.
