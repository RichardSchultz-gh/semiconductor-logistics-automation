=== Standardablauf (Basic Flow)
//Der Standardablauf definiert die Schritte für den Erfolgsfall ("Happy Path")

1. Der Use Case beginnt, wenn auf der grafischen Oberfläche der Button "Daten exportieren" angeklickt wird
2. Akteur gelangt in neues Fenster, in dem er nach Daten filtern kann (Tool ID, Lot ID, Status usw.)
3. System zeigt alle gefilterten Daten an
4. Akteur bestätigt angezeigte Daten mittels button
5. Dokument wird im Laufwerk (gewünschter Ort) gespeichert
6. System erstellt Dokument im CSV-Format
7. Der Use Case ist abgeschlossen
