=== Kurzbeschreibung

Der Use Case beschreibt die Aufbereitung und das Starten der Lose

=== Kurzbeschreibung der Akteure

==== Fertigungsleiter

Möchte Lose manuell starten

==== Timer

Startet den Use Case in einem vorberechneten Zeitintervall

//Vorbedingungen müssen erfüllt, damit der Use Case beginnen kann, z.B. Benutzer ist angemeldet, Warenkorb ist nicht leer...

=== Standardablauf (Basic Flow)
//Der Standardablauf definiert die Schritte für den Erfolgsfall ("Happy Path")

1. Der Use Case beginnt, wenn auf der grafischen Oberfläche der Button "StartLot" ausgewählt oder 
   der Timer aktiviert wird
2. Mitarbeiter gibt in der GUI die Anzahl Wafer (Menge), Produkt und Zielkalenderwoche an
3. Losanzahl wird errechnet
4. StartLot Intervall wird aus Zieldatum und Losanzahl errechnet - Timer wird erstellt
5. Los bekommt eindeutige Nummerierung
6. Los wird mit Hilfe von errechnetem Intervall auf Status "WAIT" gesetzt
7. Der Use Case ist abgeschlossen.

=== Alternative Abläufe
//Nutzen Sie alternative Abläufe für Fehlerfälle, Ausnahmen und Erweiterungen zum Standardablauf


==== Alternativer Ablauf 1

Wenn Mitarbeiter/Fertigungsleiter im Schritt 1 des Standardablauf eine negative Waferanzahl oder ein in der Vergangenheit liegendes Datum eingibt, dann bekommt Akteur eine Fehlermeldung.
-> Der Use Case wird im Schritt 1 fortgesetzt.

==== Alternativer Ablauf 2

Wenn Mitarbeiter/Fertigungsleiter im Schritt 2 KEINE Zielkalenderwoche eingibt, dann werden der eingegebene Anzahl an Losen eindeutige Nummerierung gegeben und direkt in Status "WAIT" gesetzt. 
-> Der Use Case ist abgeschlossen
