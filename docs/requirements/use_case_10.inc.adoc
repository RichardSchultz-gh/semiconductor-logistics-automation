== Use-Case: UC10 Maschine bearbeiten

=== Kurzbeschreibung

Der Use Case ermöglicht das manuelle Bearbeiten von Maschinen im Produktionsprozess. 

=== Kurzbeschreibung der Akteure

==== Fertigungsleiter

Möchte eine bestimmte Maschine manuell prozessieren.


=== Vorbedingungen

*Vorbedingung 1:* Maschinen sind vorhanden 


=== Standardablauf (basic flow)

1. Der Use Case beginnt, indem der Maschinenzustand überprüft wird.
2. Maschine ist im Zustand "IDLE".
3. Lose werden auf die Maschine gesetzt.
4. Die Maschine geht vom Zustand "IDLE" über zum Zustand "PROC". Die Maschine bearbeitet Lose.
5. Produktionsprozess ist abgeschlossen und Maschine wird wieder auf den Zustand "IDLE" gesetzt.
6. Der Use Case ist abgeschlossen.

=== Alternative Abläufe

==== Alternativer Ablauf 1

Schritt 2: Der Fertigungsleiter kann nach manueller Prüfung die Maschine von "IDLE" auf "MAINT" setzen. 
Maschine ist in Wartung und nach Überprüfung kann sie entweder wieder auf "IDLE" oder "DOWN" gesetzt werden. 
*Wenn Maschine auf "IDLE" dann wird der Use Case in Schritt 2 fortgesetzt.


==== Alternativer Ablauf 2

Schritt 1: Wenn der Maschinenzustand "DOWN" ist dann kann der Fertigungsleiter manuell die Maschine in "MAINT" oder "IDLE" setzen.
*Wenn Maschine auf "MAINT" dann wird der Use Case in ALternativ Ablauf 1 fortgesetzt.
*Wenn Maschine auf "IDLE" dann wird der Use Case in Schritt 2 fortgesetzt.
==== Alternativer Ablauf 3

Schritt 5: Maschine kann durch den Fertigungsleiter manuell vom "PROC" Zustand zu "MAINT" oder "DOWN" übergehen. 
*Wenn Maschine auf "DOWN" dann wird der Use Case in Alternativ Ablauf 2 fortgesetzt.
*Wenn Maschine auf "MAINT" dann wird der Use Case in Alternativ Ablauf 1 fortgesetzt.
