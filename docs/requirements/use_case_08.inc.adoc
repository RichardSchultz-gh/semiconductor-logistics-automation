== Use-Case: UC08 Backup erstellen

=== Kurzbeschreibung
//<Kurze Beschreibung des Use Case>
Der Use Case beschreibt das Speichern von Daten als Backup-Datei.

=== Kurzbeschreibung der Akteure

==== Fertigungsleiter

Möchte manuell ein Backup erstellen 

==== Timer

Erstellt automatisch zu einem vorgegebenen Zeitintervall/-punkt Backups

=== Vorbedingungen
//Vorbedingungen müssen erfüllt, damit der Use Case beginnen kann, z.B. Benutzer ist angemeldet, Warenkorb ist nicht leer...

*Vorbedingung 1:* Akteur hat erforderliche Rechte

*Vorbedingung 2:* Zu speichernde Daten sind vorhanden

=== Standardablauf (Basic Flow)
//Der Standardablauf definiert die Schritte für den Erfolgsfall ("Happy Path")

1. Der Use Case beginnt, wenn auf der grafischen Oberfläche der Button "Backup erstellen" ausgewählt wird.
2. manuelles bestätigen durch Fertigungsleiter
3. Dateiname und Speicherort werden von Fertigungsleiter angegeben und bestätigt
4. Rückmeldung vom System, wenn Backup erfolgreich durchgeführt wurde
5. Der Use Case ist abgeschlossen.

=== Alternative Abläufe
//Nutzen Sie alternative Abläufe für Fehlerfälle, Ausnahmen und Erweiterungen zum Standardablauf

==== Alternativer Ablauf 1

Wenn Mitarbeiter ein Backup erstellen möchte, dann Fehlermeldung (Kein Recht auf diese Operation, bitte an Abteilungleiter wenden)
-> Der Use Case wird in Schritt 2 fortgesetzt.

==== Szenario 1
