== Allgemeine Informationen

Um die grundsätzliche Funktionsfähigkeit des vertikalen Protoypen sicherzustellen wurden 2 Test Cases durchgeführt. 

== Test Cases

=== Test Case 01 - Daten anzeigen


|===
| *Beschreibung* | Der Test Case 01 stellt sicher, dass Informationen aus der Datenbank über die Webanwendung angezeigt werden können.
| *Vorbedingung* | 
  - Raspberry Pi ist hochgefahren 
  +
  - Internetverbindung ist auf dem Raspberry Pi hergestellt
  +
  - Web-Anwedung ist in einem Browser geöffnet
| *Testablauf* | 
 1. Der Button"Show Data" wird auf der Web-Anwendung gedrückt.
  +
2. Es wird kontrolliert, ob die Entitäten-Tabelle der Datenbank über die Web-Anwendung ausgegeben wird.
|===


=== Test Case 02 - Einfügen von Daten
|===
| *Beschreibung* | Der Test Case 02 stellt sicher, dass ein neuer Datensatz über die Webanwendung in die Datenbank eingefügt werden kann.
| *Vorbedingung* | 
  - Raspberry Pi ist hochgefahren 
  +
  - Internetverbindung ist auf dem Raspberry Pi hergestellt
  +
  - Web-Anwedung ist in einem Browser geöffnet
 +
  - Konsole ist auf dem Raspberry Pi geöffnet
| *Testablauf* | 
 1. In den Eingabefeldern der Webanwendung werden in den Feldern "Entity", "Class", "Note" und "State" Testdaten eingegeben.
  +
2. Über die Tickbox wird das Feld "Enabled" ausgewählt.
  +
3. Die Testdaten werden über das Drücken des Buttons "Insert Data" in die Datenbank eingefügt
 +
4. Über einen SELECT-Befehl wird in der Konsole gerpüft, ob der Datensatz korrekt in der Datenbank eingepflegt worden ist.
|===
